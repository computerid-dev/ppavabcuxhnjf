=== SETUP FIREBASE (sekali saja) ===
1. Firebase Console > Authentication > Sign-in method > aktifkan "Email/Password".
2. Firestore Database > Rules > tempel isi file firestore.rules > Publish.
3. Buat akun admin: Authentication > Users > Add user. Email: admin@esportku.app (username login: admin), isi password. Salin UID-nya.
4. Firestore Database > Start collection "admins" > Document ID = UID tadi > tambah 1 field apa saja (contoh: aktif = true).
5. Login di halaman Masuk dengan username admin, buka Panel Admin, klik "Isi kategori bawaan", lalu "Buat PIN baru" untuk dibagikan ke pengelola.
